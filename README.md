# Exercício 10 - Soma de Dois Números



## Descrição



Este programa solicita dois números inteiros ao usuário, realiza a soma dos valores e apresenta o resultado caso a soma seja maior que 10.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém dois números inteiros informados pelo usuário.



## Saída



O programa apresenta o resultado da soma caso o valor seja maior que 10.
